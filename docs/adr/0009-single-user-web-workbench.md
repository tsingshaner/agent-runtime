# 首版 Web 工作台采用单用户自托管边界

apps/web 首版面向单用户自托管，登录保护整个工作台，不引入多用户账号、项目成员或租户所有权模型。相比直接建设多人服务，这保留现有项目资源模型并缩小身份管理范围；未来支持多人时必须重新设计资源所有权与访问隔离，不能仅增加账号注册。

工作台沿用现有 Agent 会话能力，以聊天为主并呈现工具执行、审批、补充输入和取消操作。资源管理范围为 Skill 导入、查看和项目启停，MCP 连接配置和启停，Knowledge 的 Markdown 增删改查，以及 Memory 查询、删除和写入状态查看；首版不提供 Skill 脚本编辑或记忆手工改写。

登录使用服务端生成的访问令牌，网页与 API 同源部署，远程访问通过 HTTPS 域名提供。项目在界面中显式呈现，首次使用引导创建项目并填写服务端工作目录；聊天、Knowledge 和 Memory 跟随当前项目，Skill 与 MCP 从共享资源中按项目启用。

首版 Web 仅开放 Codex，会话创建时使用部署配置中的默认模型并允许修改，创建后固定 runtime。Skill 从服务端目录导入；MCP 密钥通过服务端环境变量引用，Memory 服务由部署者预先配置。网页提供未配置 Memory 时的指引，不承担密钥保管或 Memory 服务安装。以上范围限制针对 Web 入口，不移除后端已有的其他 runtime 能力。

前端采用 React、Vite、TypeScript、TanStack Router 及相关 TanStack 技术栈、Base UI 和 Tailwind CSS，复用现有 oRPC 契约与事件流处理。界面使用中文，桌面优先并适配手机；左侧为项目与会话，主区为聊天，资源管理使用独立页面。

浏览器登录通过 HttpOnly Cookie 保持 7 天并支持主动退出，不将访问令牌存入 localStorage；服务器重启后令牌轮换，需重新登录。首版提供文本输入、Markdown 回复、代码块复制、创建时填写会话标题、历史查看、归档与恢复，不提供附件、会话重命名或删除。刷新与断网只恢复已有运行的事件订阅，不重复提交运行；同一会话运行期间不排队发送新消息。

Knowledge 在项目设置中绑定服务端已有 Markdown 目录，未绑定时提供引导，绑定后提供文档增删改查、搜索与预览。
